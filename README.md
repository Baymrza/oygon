# Ойгон — цифровой иммунитет молодёжи

Платформа в формате соцсети, которая учит школьников и студентов узнавать манипуляцию и вербовку в сети.
Хакатон Digital Hackathon Osh (информационная безопасность и борьба с экстремизмом).

- Лента и афиша «Призываем к хорошему»
- Игра «Путь пяти городов» (квест с красными флагами), изометрическая игра «Дозор» и быстрый квест «Закрытый чат»
- Тренажёр эмоционального иммунитета
- Проверка: реальные истории с источниками, учебные истории, медиаграмотность, проверка контента
- Поддержка, добровольные обращения («Сообщить») и демо-админка (`#/admin`, код `1234`)

Два языка (русский и кыргызский), светлая и тёмная тема, поиск по материалам.

Статический сайт без сборки: `index.html`, `style.css`, `theme.css`, `app.js`, `game.js`, `data.js`, `i18n*.js`, `games/dozor.html`, папка `assets/`.

Запуск локально:

    python -m http.server 5188

Открыть http://localhost:5188. Все сюжеты вымышленные и учебные; данные хранятся только в браузере (localStorage).
